# Round 7 — 严格 MACs 预算下的架构冲刺：系统性负结果 + J1 配平即最优

日期：2026-08-08 · 状态：**完成** · 指标 QAT clean (test 5400)，J1 配方（SGD lr0.05, QAT v5）
输入：R6 findings（宽度>RF>深度、stem5 高效、MaxPool 最优、深度可砍、head 加宽 R3 曾有效）

## 结论先行

**在 ≤2M（含 ≤1.5M）严格预算内，7 个候选架构在 160ep 决赛口径下全部未能超过 J1。**
J1（stem 3×3s2 C0=16 + 全 1×1 (1,2,2) + head128，1.38M）是一个稳健的局部最优：
160ep 两种子 96.30 / 96.24（mean 96.27）。改进精度必须加预算（>2M，见文末）。

## 为什么 J1 配平是最优（机制解释）

R6+R7 联合给出的约束曲面：
1. C0（stem 宽度）是瓶颈资源，压到 ≤14 即崩（b/c/f/g 一致）；C0=16 + k3 是 32×32 分辨率下 MACs 最优的底层特征提取方式；
2. 深度 (1,2,2) 恰好：砍到 (1,1,1) −0.37，加到 (1,3,3)/(2,4,4) 不赚——stage 内第二次 1×1 混合是宽度生效的前提；
3. 宽度 [16,32,64,128] 与下采样节奏匹配，±10% 扰动（w110）无收益；
4. 任何"挪 MACs"都输给"加 MACs"：w150/w200/rf_s2k3 的增益全部来自预算外。
