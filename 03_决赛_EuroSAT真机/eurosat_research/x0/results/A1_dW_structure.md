# A1 — δW 内部结构分解报告

> 数据：`x0/data/probe_pairs/`（5 层 probe pairs，板上 dump）。脚本：`x0/scripts/a1_dw_structure.py`（可复跑，结果另存 `results/a1_dw_structure.json`）。
> 核心问题：等效权重扰动 δW 是否为 per-element iid（qat_v8 的建模方式）？若不是，"加宽通道按 1/√cin 稀释 δW"的假设要修正多少？

## 方法

每层依次：

1. **全局回归**：`hw ≈ α·ideal + β` → 残差 R（与 probe_fit.py 同口径）。
2. **逐列增益/偏移**：`R[:,j] = g_j·ideal[:,j] + c_j` → R2（offset/gain 单独计，不再混入 δW）。
3. **δW 回归**：`R2[:,j] = Σ_i δW[i,j]·(x[i] − x̄[i]) + int_j`（X 按列中心化，否则 δW 列均值与截距不可分）。全量 + 随机 split-half 两份估计 dW1/dW2。
4. **零假设**：R2 行置换后重估 δW_null（3 次取中位），保留 X 与估计噪声的全部统计，作为所有结构指标的基线。
5. **无偏能量分解**：分量能量用 split-half 交叉内积 `E = ⟨comp(dW1), comp(dW2)⟩` 估计——估计噪声在两半间独立，交叉内积只保留真实 δW 能量。split-half 可靠性 r = corr(dW1, dW2) 给出数据充分性度量。
6. **稀释律直接测量**：随机输入通道子集 S（|S|=k'），算 `V(k') = E[(Xc[:,S] @ δW[S,:])²]`，log-log 斜率得指数 γ（绝对误差 std ∝ k^γ）。同法测 δW_null 作基线，报**超额**指数 γ_exc（V_real − V_null 的斜率）。

其他结构检验：

- **SVD/有效秩**：δW_hat 有效秩 4.4 / 4.6 / 6.9 / 14.1 / 13.3，与置换零假设（4.1 / 5.6 / 9.6 / 13.0 / 15.0）几乎相同——**谱的整体形状并不显著低秩**；但 top-1 奇异值占比持续高于零假设（0.42 vs 0.38；0.33 vs 0.23；0.18 vs 0.17），即**领先少数几个方向承载真实的结构化能量**，其余大尾部与 iid 不可区分。
- **行 RMS 差异（哪些输入通道更"脆"）**：row-rms 变异系数 real vs null = 0.41 vs 0.42（s1a）、0.42 vs 0.41（s2a）、0.33 vs 0.33（s2b）、0.22 vs 0.22（s3a）、0.51 vs 0.49（s3b）——**观察到的行间幅度差异几乎全部由估计噪声解释**，真实 per-输入通道结构主要是上表的行均值分量（2–7% 能量）。结论：不存在少数系统性"脆"输入通道。
- **列 RMS 差异**：col-rms CV real/null ≈ 1.25–1.47 倍（全部 5 层 real > null），输出列间 δW 幅度有真实但温和的不均匀。
- **8×2 tile 块相关**：块均值方差 / 零假设 = **20.9（s1a）** / 4.0（s2a）/ 2.6（s2b）/ 1.3（s3a）/ 1.05（s3b）。**浅层同一物理 tile（8 输入 × 2 输出）内的 δW 强烈共变，逐层衰减，深层消失**——与"共享 MZI 网格/驱动"的物理直觉一致。s1a 跨种子 17.6–22.1，稳健。
- **与激活方向的对齐比**（out-of-sample，shuffle 基线=1）：0.42 / 0.13 / 0.24 / 0.26 / 0.15（零假设基线 0.04–0.11）。δW 能量**偏向激活低方差方向**（反对齐），幅度约为估计噪声反对齐的 2–4 倍，是真实性质而非纯估计伪影。

## 对"宽度稀释"假设的修正（核心结论）

1. **"1/√cin 稀释"不成立，但方向不是更坏而是界于其间。** 1/√cin 稀释要求绝对误差不随 k 增长（γ=0）；实测 δW 诱导误差随通道数增长，γ_exc ≈ **0.2–0.3（浅层 s1a–s2b）、≈ 0.45–0.5（深层 s3a–s3b）**。
2. **相对误差的稀释指数**（信号 std ∝ k^0.5，权重方向非相干的常规假设）为 γ_exc − 0.5：**浅层 ≈ k^−0.2~−0.3（加宽一倍，相对误差降到 0.81–0.86×）；深层 ≈ k^0（基本无稀释）**。对比：朴素 1/√cin 预期 0.71×，纯 iid δW 预期 1.0×（无稀释）。即：**浅层 δW 比 iid 略"好稀释"（得益于 δW 偏向低激活方差方向 + 块/低秩结构未占满激活相干方向），深层与 iid 一样不稀释**。
3. **δW 的非 iid 结构真实存在但不改变缩放律的符号**：行均值分量仅 2–7% 能量、无系统性"脆"输入通道；结构化能量主要在浅层的 8×2 tile 块共变（s1a 超零假设 21×）和少数领先奇异方向。这些结构是**输出幅度/方向**层面的，而非**通道相干增长**层面的（相干分量 grand-mean 仅 ~1–2%），所以它们不改变 γ，只改变绝对误差大小。
4. **对架构决策的含义**：在 ≤2M 预算的 J1 尺度附近，"靠加宽通道稀释 δW"对深层 1×1 光计算层（s3a/s3b 正是参数/MACs 大头）**收益近似为零**；稀释红利只在浅层小通道层存在且温和（k^−0.2 左右）。宽度路线相对 RF 路线的论证**不应计入 δW 稀释收益**；若某条臂主要靠加深加宽 s3 段提分，δW 不会是它相对 RF 臂的额外风险或额外红利。
5. **对 v10 噪声模型的含义**：δW 按 per-element iid 注入在深层是可接受近似（s3a/s3b 的 iid 尾占 58–74% 且 γ≈0.5），但在浅层会低估结构化误差：建议 v10 对 s1/s2 段增加 (a) 8×2 tile 块级相关抖动（块均值方差 s1a ≈ 20× 元素级），(b) 少量低秩方向分量；per-输入通道系统项（2–7%）可作可选小项。

## 局限

- **s3b 可靠性 0.09**（N=1024 vs k=128，残差大）：该层所有结构数字只给量级，γ_exc 取 0.43–0.56 区间；若要收紧需板上补 dump s3b（建议 ≥4096 行）。
- γ 测量基于现有通道子集采样，外推到 2×k 假设新增通道统计与现有通道同类；权重方向相干性（真实训练权重可能与激活相干方向对齐，使 γ_sig > 0.5）未建模，该情形下相对稀释会更差，本结论"深层无稀释"已是偏乐观口径。
- 增益组分口径（先于 δW 剥离 per-col gain）使本文 δW 能量略小于 C3 的 δW 口径；gain 本质是 rank-1 列缩放型 δW（δW[:,j] = g_j·W[:,j]），若计入则结构化占比进一步上升、但不影响 γ 结论。
