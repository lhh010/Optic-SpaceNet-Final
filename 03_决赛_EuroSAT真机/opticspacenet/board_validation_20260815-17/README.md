- 单次调用（校准+跑批）≤30min：校准耗时从预算扣除（M9/M10 实测 calib 9–15min → 跑批 LIMIT 自动缩减）
- 两次调用间 >5min 空余（冷却 6min）；acc < 预期−5pt → 冷却升级 30min + ALERT
- 每 3 段 fresh chip compass_cali + EBR 复查（EBR 全程 9.48–9.93）
- 0% 段自愈重采；开窗四判据（EBR≥8 / error_std / MNIST canary / mini-run）
