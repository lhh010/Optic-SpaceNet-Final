## 五、发现与修复（3 个工程 bug）

1. **板上测试数据仅 1000 张**（08-14 [1200:] "全崩"根因之一）→ 本地 PIL+numpy 复刻 torchvision 管线生成 5400 张，与 canonical 前 1000 张**逐位一致（maxdiff=0.0）**后上传
2. **probe/calib 脚本硬编码 `test_images_j1.npy` + meta 路径不一致** → 5400 权重目录复制同名文件 + meta 指向修正
3. **bash 小数算术 bug**：`RATE=17.5` 使 `$((RMAX*RATE))` 崩 → 改整数；**calibrate_col 中文 print 在 ascii locale 崩** → `PYTHONIOENCODING=utf-8`；**固定段距 vs 浮动 LIMIT 导致漏样本** → 动态 OFFSET 累加（OFF += LIMIT）
4. 官方 `calibrate_sample.py` 有 bug（`if __init__ =='__main__'`）→ 用 CLI `compass_cali` 替代
