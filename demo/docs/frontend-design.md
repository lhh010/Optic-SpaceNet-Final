# Model 3 光计算演示 — 前端设计

> 2026-07-17 · 状态: 已实现并真机烟测通过 · 关联: design.md(总设计), api.md(契约)
> 决策记录(与用户逐项确认): 深色光子科技感 / 单屏三栏 Dashboard / 服务端渲 PNG /
> 简单进度指示 / 引入框架并本地化(零外网依赖)。

## 目标

单屏一瞥向评委讲清三件事: **系统能跑**(真机 gazelle-osim 推理, 逐层耗时可查)、
**有用**(双路径预测一致且正确)、**为光计算优化**(逐层 feature map 光|电对比 + 指标面板)。

## 技术栈

- `demo/web/`: `index.html` + `app.js` + `vendor/`(Tailwind Play CDN 本地化 + 等宽字体 woff2)。
- 无构建步骤, FastAPI 静态直出; 运行时**零外网请求**(现场网络不可控, 全部资产本地化)。
- 样式: Tailwind utility 为主 + 少量自定义 CSS(辉光、进度脉冲动画)。

## 契约变更(api.md 已同步)

- `Layer` 新增 `grid_b64`: PNG base64, 由本地后端新增模块 `demo/server/render.py` 生成。
- 渲染规则从「前端职责」上移到本地后端:
  - 同层光|电两个激活**拼接后共享 min/max 归一化**(对比公平性由后端保证);
  - conv 层取前 16 通道渲 4×4 网格, 光左电右一张图, 中间细分隔线;
  - fc 层渲 1×N 条带(光上电下);
  - 伪彩 LUT: 深蓝 → 青 → 亮白(贴合光子主题; 手写 LUT, 不引 matplotlib)。
- `act_b64` 保留(向后兼容 + 调试); render.py 在 `/api/infer` 聚合阶段就地注入 `grid_b64`。

- 顶栏: 标题 + health 状态灯(绿=gazelle-osim / 黄=fake 降级 / 红=down)+ 关键指标 chips
  (数据来自 `/api/metrics`, 页面加载时拉取)。
- 左栏(输入): 128px 预览、label/index、类别下拉(10 类+随机)+抽图、上传、「开始推理」主按钮。
- 中栏(主角): 6 行逐层对比。每行 = 层名 + spec + `光`/`电`徽标 + 一张拼接 grid PNG +
  双侧耗时。光路径耗时醒目显示(秒级 vs 电 ms 级, 本身就是「真机在跑」的证据)。
- 右栏: 双路径 pred 大字对比 + top-k 概率双条形(光=青, 电=灰蓝) + correct ✓/✗ +
  指标面板(MOPs、参数量、真机单张耗时等)。

## 交互与状态

1. 页面加载 → `GET /api/health` + `GET /api/metrics` 渲染顶栏与右栏指标。
2. 抽图/上传 → 预览就绪 → 「开始推理」可用。
3. 推理中: 按钮变脉冲 spinner + 文案「光计算推理中…」+ 秒表计时(简单进度指示, 无复杂动画)。
4. `meta.degraded=true` → 顶部黄色警示条「远程不可用, 已降级本地 fake 引擎」。
5. health remote=down → 状态灯红 + 提示「推理将走降级链」; infer 503 → 错误条。
6. 上传图(label=null)→ 不显示对错, 仅显示双路径预测。

## 视觉语言

- 深空蓝黑底(#05070f 级); 光路径 = 青(#22d3ee)+ 金色(#fbbf24 点缀)辉光,
  电路径 = 中性灰蓝(#64748b); 细光线/光晕点缀, 克制不花哨。
- 数字与英文标识用等宽字体(本地化 JetBrains Mono); 中文系统字体栈。
- 目标分辨率: 现场 1080p 投影, 最小适配宽度 1280px, 字号偏大保证后排可读。

## 风险

| 风险 | 应对 |
|---|---|
| 投影对比度/字号不够 | 深色高对比 + 大字号; 截图自审时按 1080p 核对 |
| Tailwind Play 本地化异常 | vendor 文件随仓库走, 无运行时下载; 异常时打印台报错可见 |
| 中栏 6 行超高 | grid 渲染尺寸固定(每格 ~28px), 整列 1080p 内排布; 必要时中栏内部滚动 |
