**关键结论:**
- **真实硬件 gap 仅 ~1 点** (osim 90.80% vs val 91.83%, Δ −1.03%; vs fp32 test 92.13%, Δ −1.33%)。训练时的 Gazelle 噪声配方 (DAC ENOB 7.5) 与 osim 硬件模型吻合, 真机精度基本保住。
- **osim ≈ val** (Δ −1.03%, 在 500 张 ±1.3% CI 内) → 干净泛化, 无泄漏 ✓。对比旧 leaky osim **93.26% (作废)**。
- **88% (quick 50) 是假象**: 50 张抽样 + osim 每跑随机的噪声实现的一次偏背结果, 非真值。前半段跑到 ~92%、后半段回落到 90.8% 是不同批次图像难度的采样波动 (运行均值收敛), 非模型退化。**500 张的 90.80% 才是可信数。**
- 光计算占比 90.65% 满足部署阈值 (≥90%)。

**关键结论:**
- **全量 90.28% 取代 q500 90.80%**: 两值一致 (都 ≈ val 91.83%, Δ ~1 点), 全量为可信真值。q500 的 90.80% 偏高 ~0.5 点 (n=500 抽样, SE≈1.3%)。
- **真实硬件 gap ~1.6 点** (osim 90.28% vs val 91.83%, Δ −1.55%; vs fp32 test 92.13%, Δ −1.85%): 训练时 Gazelle 噪声配方 (DAC ENOB 7.5) 与 osim 硬件模型吻合, 真机精度基本保住。残留 ~1.6 点为 osim 物理噪声 (DAC + TIA σ=5.31) 相对干净伪量化的损失。
- **干净泛化, 无泄漏 ✓** (osim ≈ val, test∩train=0)。对比旧 leaky osim **93.26% (作废)**。
- **与 Model 2 真机打平, gap 基本相等** (M2 全量 90.43%, Δ vs val −1.63%): 见 `log_optic_int8_new.md`。**"KD 提升光计算噪声鲁棒性" 不被全量支持** (M2-vs-M3 直接差 0.15%, z≈0.27 不显著) — q500 时 "M2 gap (~3 点) > M3 (~1 点)" 纯属抽样噪声。
- 光计算占比 90.65% 满足部署阈值 (≥90%), 硬件对齐率 99.6%。本全量数已回写 EXPERIMENTS.md §11.13 / §13。
